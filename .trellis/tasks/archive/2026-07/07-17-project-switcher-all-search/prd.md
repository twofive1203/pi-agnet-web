# 项目切换支持查看全部和搜索

## Goal

让使用过多个工作目录的用户既能快速访问最近项目，也能在同一个项目切换器中查看并搜索全部历史项目，不再受固定 5 项限制。

## Confirmed Facts

- 项目切换器位于 `components/SessionSidebar.tsx`。
- 项目候选来源于 `/api/sessions` 返回的活动会话 cwd，并补充只有归档会话的 cwd、当前选中 cwd 和 WorkTree 相关 cwd。
- 当前 `getRecentCwds()` 按 cwd 最近会话修改时间倒序排序，并在最后通过 `.slice(0, 5)` 限制候选。
- WorkTree 通过 `buildCwdPickerRows()` 归入主项目下显示；项目切换后现有会话、文件标签和 Git UI 由 `AppShell` 按现有逻辑重置。
- 用户仍可通过 `Custom path…` 验证并切换到未出现在历史会话中的目录。

## Requirements

- 项目切换器默认保持紧凑，只展示最近或优先级最高的 5 个项目组。
- 当完整候选数超过默认展示范围时，提供“查看全部”入口。
- 全部模式展示所有来自现有会话与归档数据的项目，并提供即时搜索。
- 搜索应过滤完整候选集合，不改变项目最近使用排序，不修改服务端数据。
- 搜索和查看全部不能破坏主项目与 WorkTree 的分组关系、选中状态、归档标识和右键 WorkTree 操作。
- 保留 `Use default directory` 和 `Custom path…` 入口及其现有行为。
- 打开/关闭下拉框和成功选择项目时，应清理临时搜索/全部模式状态，确保下次打开仍从最近 5 个开始。
- 使用语义化按钮和输入框，并为搜索提供清晰的可访问名称。

## Acceptance Criteria

- [x] 历史项目不超过 5 个时，切换器保持现有紧凑列表且不显示无意义的“查看全部”。
- [x] 历史项目超过 5 个时，默认只显示最近或优先级最高的 5 个项目组，并显示“查看全部”入口及总量提示。
- [x] 点击“查看全部”后，同一切换器内展示完整项目列表和搜索输入框。
- [x] 输入路径中的任意大小写不敏感片段，可实时过滤项目；无结果时显示明确空状态。
- [x] 清空搜索恢复完整列表，关闭后重新打开恢复最近 5 个默认视图。
- [x] 选择搜索结果可正常切换 cwd，并保持现有会话过滤、文件浏览器和 AppShell 重置行为。
- [x] WorkTree 分组、`(main)`、`(archived)`、选中勾选和右键菜单仍正常。
- [x] `Use default directory` 与 `Custom path…` 在两种视图中均可用。
- [x] `npm run lint` 和 `node_modules/.bin/tsc --noEmit` 通过。

## Out of Scope

- 扫描磁盘自动发现没有 Pi 会话记录的项目。
- 新增服务端项目收藏、固定、删除或持久化排序能力。
- 修改 `/api/sessions` 数据协议或会话/归档存储结构。
- 搜索会话标题、消息内容或文件内容。

## Interaction Decision

- 点击“查看全部”后，在原下拉框内切换为“顶部搜索框 + 全部项目可滚动列表”。
- 全部模式提供“最近项目”返回入口；搜索仅匹配完整 cwd 路径。
