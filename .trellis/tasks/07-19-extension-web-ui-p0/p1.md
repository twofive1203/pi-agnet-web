# P1: Extension resources panel + settings page

## Scope

1. **Resources panel** — UI over `GET /api/pi/resources` (+ packages list)
2. **Extension settings** — discover registered settings via event bus; read/write `settings-extensions.json`

## Non-goals

- Install/remove packages from UI
- Full powerbar rendering
- TUI custom components

## Acceptance

- [x] Sidebar has Extensions entry opening a modal
- [x] Resources tab shows packages, extensions, tools, commands, skills, prompts, diagnostics
- [x] Settings tab shows registered settings (e.g. powerbar) with cycle/select/text editors
- [x] Saving writes `~/.pi/agent/settings-extensions.json`
- [x] Orphan stored keys without schema still visible/editable
- [x] lint + tsc pass
- [x] docs updated
